
# 🤖 DadBot AI v3

DadBot AI is a premium ChatGPT-style AI assistant with:

✨ Glassmorphism UI  
🤖 Groq AI backend (free tier)  
🎙 Voice input + output  
💬 Chat memory  
📱 Mobile responsive design  
⚡ Fast performance  

---

## 🚀 Setup

### 1. Install Vercel CLI
npm i -g vercel

### 2. Add API key in Vercel
GROQ_API_KEY=your_key_here

Get key:
https://console.groq.com/keys

---

### 3. Run locally
vercel dev

---

### 4. Deploy
vercel --prod
